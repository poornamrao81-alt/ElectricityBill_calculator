# ⚡ Electricity Bill Calculator

## 📌 Description

The **Electricity Bill Calculator** is a simple Python project that calculates the electricity bill based on the number of units consumed.

The program uses different **unit slabs** with different rates and calculates the total bill accordingly.

This project was created as a beginner-level Python project to practice **functions, conditional statements, user input, and arithmetic operations**.

## 🛠️ Concepts Used

* `input()`
* Variables
* `if`, `elif`, and `else`
* Functions
* Arithmetic operators
* `return` statement
* `float()`
* Formatted output

## ⚙️ How It Works

The program asks the user to enter the number of electricity units consumed.

It then checks the number of units and applies the appropriate slab rate to calculate the electricity bill.

The project uses the following practice tariff:

| Units Consumed |        Rate |
| -------------- | ----------: |
| 0–100          | ₹2 per unit |
| 101–200        | ₹3 per unit |
| 201–300        | ₹5 per unit |
| Above 300      | ₹7 per unit |

The rates used in this project are **practice rates**.
